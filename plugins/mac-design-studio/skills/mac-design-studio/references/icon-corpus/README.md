# icon-corpus — raw icons + per-icon analysis

Corpus assembled 2026-08-07 for `mac-design-studio` icon work.

- `apple-2026/` — 32 ground-truth macOS 26 "Tahoe" era captures (Apple system apps + third parties shipping the current idiom), from user screenshots 2026-07-26. `apple-01` = Mail … `apple-32` = Maps; per-file identification in `analysis/apple-2026.md`.
- `macosicongallery/` — the 500 most recent icons from macosicongallery.com (Jim Nielsen's gallery), 256px PNGs, spanning 2022-02 → 2026-07. `manifest.json` maps each file id → app name, date, designer, developer.
- `analysis/` — per-icon vision analysis:
  - `batch-01…10.md` — 50 icons each (newest first; batch-01 = 2026-04→07 … batch-10 = 2022), one structured block per icon (era / ground / glyph / light+material / palette / notable / grade) + a batch summary.
  - `apple-2026.md` — the 32 Tahoe captures, same format, + the "Tahoe gel-glass grammar" synthesis.
  - `SYNTHESIS.md` — cross-batch aggregate: era census + adoption timeline, both eras' fingerprints, A-grade exemplar roster, failure-mode anti-checklist. **Read this one first**; the distilled design guidance lives in `../icon-directions.md`.

Images are for analysis/reference (style study), not for redistribution as artwork.
