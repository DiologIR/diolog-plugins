## Batch summary

**Era distribution (n=50):** big-sur 31, skeuomorphic 9, flat-brand 5, custom-web 5, liquid-glass 0. This 2024 batch is peak late-Big-Sur: saturated gradient squircle + rendered hero object is the default grammar. No true Liquid Glass yet, but its precursors are visible (see material trends).

**Dominant palette families:** Blue is overwhelmingly the default ground (12+ icons: Whisper, Helm, Brewer X, Navi, Couverture, Menu Weather, Pricetag…), followed by purple/violet (DBngin, PasteNow, Taska, Persona, Astro, Usage, Pictura), then warm cream/tan neutrals (TablePlus, TableTool, OSCsmith) and dark charcoal grounds for pro/utility tools (PolyCapture, PDF Squeezer, ScreenSnapAI, GPU Monitor, Usage). Accent discipline is the quality separator: the best icons run one hue family plus at most one accent (PolyCapture's single green pill, Persona's mint lens); the weakest run three metaphors in four palettes.

**Recurring glyph devices:** hero-tool-object over ghosted/blueprint UI (OK JSON, Brewer X, Pricetag, Kolibri, Helm); document/list + pen or prop (Taska, Budget Seer, Note Widget, Text Workflow); magnifier-on-thing (TableTool, Remote Desktop Scanner); screen/window + tool (CleanMyMac, System Toolkit, ScreenFloat, ScreenSnapAI); robot/mascot narrative (LUT Robot, Metaburner, Mass Rename); letterform marks (Bezel, PasteNow); capture corner-brackets (ScreenFloat, ScreenSnapAI); database cylinder, mic-on-blue, umbrella — the standard nouns.

**Material trends / proto-Liquid-Glass tells:** (1) frosted translucent white gel glyphs on saturated grounds — Navi's milky speech bubbles are the clearest pre-echo of Liquid Glass layered translucency; (2) near-white/blush grounds with a jewel-gloss object (CleanMyMac, Screens 5/org, Spring) anticipating the light frosted look; (3) soft gel/clay extrusion with creamy AO instead of hard bevels (Persona, Astro, Scrobbles' concave dish); (4) emissive-as-AI-signifier — glowing wireframe gems, scan beams, and gauge segments (Pictura, ScreenSnapAI, Usage, Perplexity, Capacitor) with real bloom; (5) pearlescent/iridescent spectrum fields disciplined by an achromatic glyph (Spring). Classic 2010s gloss survives only in utility-ware (System Toolkit, Whisper).

**A-grade standouts:** TablePlus (facet-as-shading origami — modelling entirely through discrete flat tones, timeless at any size); CleanMyMac (the wiped-glass specular literally performs the product promise; MacPaw's near-white ground + magenta jewel is era-defining); PDF Squeezer 4 (verb-icon perfection — the machine squeezes the format; steel/vinyl/enamel material contrast is masterful); Capacitor (cinematic emissive rendering — bloom, falloff and ambient spill done properly inside a clean X silhouette); Couverture (appetizing material storytelling with drip physics on a spotless silhouette); Astro and PolyCapture close behind for single-accent discipline.

**Most common failure modes:** (1) generic-formula collage — screen + wrench/magnifier with no identity (System Toolkit, Remote Desktop Scanner); (2) photographic/micro-detail texture that bakes to mud at dock size (News Import's concrete, Docktor's curtain, Mass Rename's AI-render noise); (3) full-bleed marketing/game art ignoring macOS composition (Cut the Rope 3, the installer-disc wallpapers); (4) template mimicry of Apple's own apps (Note Widget); (5) metaphor soup — three unrelated symbols sharing one canvas (Docktor, Privacy Cleaner's vault+brush collage); (6) broken squircle silhouettes from oversized props (Budget Seer's binoculars, Mass Rename's freeform clipboard).
