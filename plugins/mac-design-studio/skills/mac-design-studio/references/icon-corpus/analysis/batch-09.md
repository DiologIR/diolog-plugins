## Batch summary

**Era distribution:** big-sur 30 · flat-brand 9 · skeuomorphic 8 · custom-web 3 · liquid-glass 0. This 2022–2023 window is peak Big Sur orthodoxy: saturated gradient squircle + one dimensional object, with Apple's own pro/dev tools (blueprint linework, doc-plus-tool, crossed tools + badge) setting the grammar third-party icons imitate (Coduo, Mango 5Star, Simulator all wear the blueprint costume).

**Dominant palettes:** systemBlue gradients are by far the most common ground (8 icons: Wireless Diagnostics, Accessibility Inspector, TestFlight, ShellFish, Coduo, Proxyman, Elpass, Mango). Second tier: violet/magenta fields (Affinity Photo, ScreenSearch, YarnBuddy, HiDock, OmniFocus, Action Camera) and near-black grounds carrying one emissive or white object (Instruments, Stocks, Flighty, Raycast, Pitch). The strongest icons run one hue family plus neutrals; the weakest run four+ saturated hues (Cashculator, Badminton).

**Recurring glyph devices:** magnifying glass with real refraction (Accessibility Inspector, ScreenSearch); doc/window + diagonal tool pen (FileMerge, Font Proofer, RapidWeaver, Coppice); checkmark (OmniFocus, Tasks, Opus One); speech bubbles; blueprint/wireframe linework (Instruments, TestFlight, Simulator, Create ML, Coduo, Mango); mascot-object on plain field (Proxyman helmet, YarnBuddy ball, Franz device); silhouette-breaking physical objects in the old Mac tradition (Pasty folder, Opus One notebook, Cashculator coin, Franz, Night Owl, Gyroflow case, Plasticity).

**Material trends / Liquid Glass pre-echoes:** even in 2022–23 the ingredients of the later Liquid Glass look are already assembling — frosted translucent glyphs on saturated grounds (TestFlight's mesh propeller, HiDock's frosted dock chips, Create ML's glass letter slabs), soft gel extrusions on near-white grounds with whispered background patterns (Copilot, Pasta), layered translucency for depth (Pasty's fading cards, Pitch's DOF shapes), and emissive marks on black (Instruments, Raycast, ShellFish). What's absent vs the true Liquid Glass era: no rim-lit clear-glass edge treatment, and near-white grounds are still the exception (2 of 50) rather than the default. Metal bevel frames (Marker Toolbox, Elpass, Raycast) read as the dying holdover.

**A-grade standouts (6):**
- **pasta** — the perfect one-object formula: near-white keyboard-relief ground, a single glossy pasta "P" with per-rib speculars, and a pun that encodes the app's function twice.
- **copilot** — gel arrow on near-white with a whispered dash pattern; the exact recipe Apple later canonized, executed with flawless restraint.
- **flighty** — monochrome discipline: one beautifully modeled white airliner on soft black, contrails at 3% opacity; proof restraint beats palette.
- **instruments** — emissive blue wireframe on black with a metal rim; the definitive "glow as the only material" icon.
- **create-ml** — translucent isometric type with blueprint annotations; dimensional lettering that stays legible and on-brand for a dev tool.
- **tasks-to-do-lists-planner** — rainbow-through-a-checkmark-cutout: maximal color budget spent through a minimal aperture.

**Most common failure modes:** (1) object-pile skeuomorphism — 4-5 rendered props with no hierarchy, mush silhouette (Librarian Pro, Night Owl, Cashculator); (2) template mimicry — wearing Apple's blueprint/dev dialect or the clapper+play video-editor kit without an ownable idea (Mango 5Star, Action Camera Master); (3) game-store art in an icon frame — full-saturation renders with no macOS material language (Badminton Clash, Ball Road); (4) dated hardware framing — heavy metal bevels and keycap gloss eating canvas (Marker Toolbox, Raycast, Elpass); (5) baked text/wordmarks doing branding work the glyph should do (Pitch, Raycast).
