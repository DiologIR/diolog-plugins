The 2025-11-14 Apple system set and the 2025-11-20 Microsoft Office refresh together make Liquid Glass nearly half the batch — the third-party utility tier (11-26 captures) is still living in Big Sur gel-3D.

**Dominant palette families:** blue overwhelmingly dominates (16+ icons use a blue ground or blue hero object — system blue #2E7BF6..#1D5FE0 range). Second tier: pure grayscale/monochrome (8 icons, mostly utilities and Apple tools). Purposeful rainbow appears only where semantics justify it (Photos, Grapher, Tasks, Highlights). Near-white grounds (#F3–F7 range) are the signature Liquid Glass canvas — 14 icons sit on one.

**Recurring glyph devices:** letter/lettermark tiles (all 5 Office icons, QuickTime); magnifiers/loupes/binoculars (Preview, Folder Preview, Folder Quick Look, Apple Remote Desktop); hardware-literal renders (GPU Monitor, System Watcher, Print Center, PolyCapture); checkmarks and list rows (Tasks, Reminders, Drive Capacity Tester badge); tools-as-identity (wrench, gear, caliper, squeegee, hammer); crop brackets/window frames (Screenshot, Rectangle, Screen Sharing).

**Material trends / Liquid Glass tells:** the era's fingerprint is consistent across Apple and Microsoft — (1) near-white ground with the mark floating on soft contact shadow; (2) frosted translucent gel slabs with per-layer rim highlights (Office set, TestFlight blades, Screen Sharing panes, Podcasts rings); (3) additive overlap — where glass crosses glass the junction *lightens* (QuickTime Q, Shortcuts diamonds, Photos petals); (4) emissive interiors under specular glass (Siri orb, Stocks cursor, Base's core); (5) soft gel extrusion replacing hard bevels everywhere. Third-party utilities lag with 2020-era glossy gel on saturated gradient grounds, and a skeuomorphic holdout tier (Xcodes, System Information) that Apple itself still sanctions for pro/utility tools.

**A-grade standouts:** Shortcuts (the definitive layered-glass construction — blur, rim glow, additive overlap in one mark); Sketch (facet-plane value control on a single object, the benchmark hard-candy material); CleanShot X (the page-curl literally enacts the product's function — concept and material fused); Xcodes (photoreal pegboard still-life proving high-object-count skeuomorphism can survive shrink when masses stay big); System Information (jewelry-grade machined metal in a pure-neutral palette). Honorable: Photos (translucent-overlap reference), Preview (glass-skirt loupe + micro-text charm), Rectangle (flat-brand discipline as identity).

**Common failure modes:** (1) literal hardware renders with no stylisation — muddy silhouettes and zero brand (GPU Monitor Pro, System Watcher, Image View Studio); (2) metaphor mashups that never resolve into one object (MaCleaner's dial+squeegee); (3) accent-on-matching-hue contrast loss (Magic Battery's blue Bluetooth badge on blue capsule); (4) category-glyph saturation — chips, wrenches, gears, checkmarks and magnifiers recur so often that competent execution still yields anonymity; (5) rainbow without a semantic reason (Highlights) versus rainbow earned by overlap/data semantics (Photos, Grapher); (6) dated gloss tells (lens-flare sparkles, heavy speculars) marking pre-Tahoe work.
