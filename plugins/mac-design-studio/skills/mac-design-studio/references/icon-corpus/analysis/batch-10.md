## Batch summary

**Window:** all 50 icons are Feb–Oct 2022 — squarely mid-Big-Sur era. **No liquid-glass entries exist in this batch**; its value is as the "before" baseline against which Liquid Glass tells (frosted translucent glyphs, gel extrusion, layered translucency, near-white grounds) can be contrasted. Early precursors of that language do appear: ReadKit's translucent ghost cards, Darkroom's overlap translucency, WorldWideWeb's emissive-glass globe, Core Data Lab's refracting lens, CleanMaster's hologram panel.

**Era distribution (n=50):**
- big-sur: 25
- flat-brand: 9 (the five Microsoft Fluent icons, Linear, Darkroom, Word Writing, Linea Link)
- skeuomorphic: 8 (Hand Mirror, Letter Opener, Draft Writing, GPU Benchmark, Make My App, FTP Disk, Podcast Soundboard, Gemini 2)
- custom-web: 8 (all games + CleanMaster mascot render)
- liquid-glass: 0

**Dominant palette families:** blue is overwhelmingly the default ground (14+ icons: azure, cobalt, Xcode blue, periwinkle, indigo — #2E6BC8→#8C90E8 range). Second tier: red/orange hot grounds (PDF Search, ProFind, Linea Link, bowling) and violet/purple (Sketchbook, Hypercal, CleanMyMac, MusicBox). The best icons run two-family discipline: one ground hue + one complementary object family (orange-on-purple Hypercal, salmon-on-indigo MusicBox, copper-on-teal Solitaire) or near-monochrome neutrals (The Unarchiver). Rainbow use is disciplined only when physically quarantined (Paletter's swatch chips, Sketchbook's fan on white paper).

**Recurring glyph devices:** single centered real-world object on a gradient ground (binoculars, blender, typewriter, octopus, ice-cream) is the era's core formula; drawers/boxes/containers holding content (Unarchiver, MusicBox, TopDrop's crate); magnifier-as-search (Core Data Lab, PDF Search); paper/cards in stacks (ReadKit, Solitaire ×2, Paletter); letterform-tile-plus-object (all five Microsoft); document sheet + tool (Sketchbook, Make My App, References On Tap); mascots (Hypercal, CleanMaster).

**Material trends:** matte clay/gel is the signature Big Sur read (Unarchiver, MusicBox, CleanMyMac, Gemini eggs, Hypercal) — soft top light, rounded edges, gentle AO, restrained speculars. High-gloss skeuomorphic rendering survives in freeform legacy icons (typewriter, chrome pen, FTP globe). Emissive elements on dark grounds form a clear sub-genre (WorldWideWeb globe, Piano note-gels, CleanMaster visor) — the closest 2022 gets to the later glass-glow aesthetic. True translucency is rare and precious: Core Data Lab's tinted refracting lens, ReadKit's ghost cards, References On Tap's highlighter ink, CleanMaster's hologram. Near-white grounds appear only on the Microsoft flat-brand set and Unarchiver's cream — the near-white-ground + frosted-glyph combination that defines Liquid Glass is entirely absent.

**A-grade standouts (5):**
1. **The Unarchiver** — near-monochrome warm neutrals, perfect silhouette, matte cardboard/paper material honesty; the reference for restrained utility icons.
2. **Dropzone 4** — layered hover-stack with floating shadows that diagrams the app's behavior; analogous palette + one warm emissive accent.
3. **Couverture** — best material storytelling in the batch: semi-gloss chocolate drip viscosity vs matte mint cream; the app's name told entirely in material.
4. **Hypercal** — mascot craft: bilateral symmetry, complementary orange-on-purple, gel shading that survives 16px.
5. **Draft Writing** — lavish skeuomorphic micro-detail (individually lit keycaps, fanned type bars) that never breaks the silhouette.

**Most common failure modes:** (1) full-bleed game key-art pasted into the squircle with no icon grammar (Mining Tycoon, Road Rush, My Bowling — object clutter, edge-cropped subjects); (2) baked text in the artwork (GPU Benchmark ×2 strings, Make My App, References On Tap) which dies at dock sizes; (3) too many ideas per tile (NepTunes' third object, References On Tap's paper+marker+swoosh, CleanMyMac's badge); (4) unreconstructed legacy formats — circle plates, freeform overhangs, page curls, wood frames (Podcast Soundboard, FTP Disk, Rottenwood, Hand Mirror) that ignore the 2020+ grid; (5) stock-metaphor genericism (vinyl record for a soundboard, globe-on-drive for FTP) where the render is fine but the concept is unowned.
