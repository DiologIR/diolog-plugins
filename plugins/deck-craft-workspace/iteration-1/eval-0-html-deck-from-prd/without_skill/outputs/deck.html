Authoring model

A template is a base structure,
not a form to fill in

Use a template

Bend it. Slots expand to geometry server-side.
{
  "id": "ops-highlights",
  "templateId": "kpi-grid",
  "slots": {
    "title": "FY26 highlights",
    "kpi.1": { "value": "…" },
    "table.rows": [ … ]
  }
}

Or author from nothing

Equally first-class. Absolute layout boxes.
{
  "id": "kurri-kurri",
  "elements": [
    { "type": "image", … },
    { "type": "stat",  … },
    { "type": "text",  … }
  ]
}
Both shapes mix freely inside one deck. Templates expand to geometry server-side at apply — never expand one yourself.

Element vocabulary

Seven types survive apply. Three are dropped.

Survives
text stat table image shape line chart
Dropped — no deck mapping
group widget embed
Authoring a dropped type is silent data loss: the slide validates, applies, and renders without it. Compose with absolute layout boxes instead of grouping.

Hard rules

What the validator refuses to pass

stat.value is a figure, ≤ 14 characters
The renderer sizes it from its box, so prose there renders enormous and covers its neighbours. Words belong in label.
A value must fit its box width
Legible at that size, or the figure wraps mid-number.
Text must fit its box at its fontSize
No overflow, no silent clipping at apply.
No overlap beyond 20%
Two text-bearing elements over 20% of the smaller box print one string across the other. Also: no fully empty table rows.
Rejected "value": "Revenue up strongly on FY25"
Accepted "value": "$182.4m"
"label": "FY26 revenue, up on FY25"

schema

non-empty strings

{ w: 1280, h: 720 }
theme.tokens
authored palette wins; apply fills only what's absent
slides[]
templated or hand-authored, mixed
x.diolog.structure
one entry per slide, same order and id — archetype, visible label, 2–5 grounded bullets
$ node scripts/generated/diolog-slide-templates-skill/scripts/validate-deck.mjs deck.json slides[3].elements: 'kpi-fleet' and 'footnote' overlap by 34% of the smaller box
Fix every error it prints and re-run. Never bypass it, and never downgrade a slide to satisfy it.
